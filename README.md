## Getting Started

### Prerequisites

Install Python from the official website:

https://www.python.org/

Check your Python installation:

```bash
python --version
```

or:

```bash
python3 --version
```

### Clone the Repository

```bash
git clone <your-repository-url>
```

Move into the project directory:

```bash
cd python-basics
```

Run a Python file:

```bash
python filename.py
```
